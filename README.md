# 🚗 AI-Based Accident Detection System

An AI-powered computer vision project designed to detect road accidents and identify safe traffic scenarios from surveillance videos using deep learning.

## 📌 About the Project

This project uses YOLO-based computer vision to analyze traffic footage and identify potential accident scenarios.

The system processes video frames, detects relevant objects, and displays prediction labels, bounding boxes, and confidence scores.

Developed during my internship at **Polytope Networks**.

## ✨ Features

- Accident and safe-condition detection
- Vehicle detection using YOLO
- Video-based traffic analysis
- Bounding boxes around detected objects
- Confidence scores for predictions
- Visual detection output on traffic footage

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Object Detection:** YOLO
- **Computer Vision:** OpenCV
- **Domain:** Artificial Intelligence, Deep Learning

## ⚙️ How It Works

1. Traffic surveillance video is provided as input.
2. The video is processed frame by frame.
3. The YOLO model analyzes each frame.
4. The system identifies accident or safe scenarios.
5. Detection results are displayed with bounding boxes, labels, and confidence scores.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/jayraj027/accident-detection.git
cd accident-detection
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

Run the main Python script:

```bash
python main.py
```

> Replace `main.py` with your actual project entry-point filename.
